# 参考版式库

参考文件优先；以下适用于高校科研和技术汇报，按内容选结构，不强制每页相同密度。

960×540point候选规范：边距32；标题x32/y18，30–34pt；横线y68；内容y78–466；页码右下。深蓝073D86、红BE282B、浅蓝DFEBF5/BCD5E9、白底。正文18–24pt、图注12–16pt。优先实际参考值；过量内容先整理，不靠缩字塞入。

| ID | 内容 | 结构 |
|---|---|---|
| cover | 封面 | 居中主题、报告信息、底部色带/曲线 |
| toc | 目录 | 编号圆形、章节文字，当前章节深蓝 |
| demand | 需求 | 观点栏、图表/指标、场景图、结论 |
| problem | 问题 | 两行问题，每行2–3个图文模块，标签紧邻图片 |
| mechanism | 机理 | 大断面、准确编号引线、机制说明 |
| route | 路线 | 3–5模块、箭头、关系文字、整体目标 |
| comparison | 对比 | 同尺度两栏、准确几何/图表、差异结论 |
| metrics | 指标 | 分类矩阵或真实图表，区分阈值/实测 |
| cases | 案例 | 匹配场景、参数、效果证据；地图用可靠底图 |
| summary | 总结 | 分类标签、分行观点、红字关键词 |

标题横线、浅蓝观点栏、细边框、标签、底部结论栏用原生对象。图片承担解释任务；移除后信息完全不变时检查是否纯装饰。主体过小应裁切留白或补生成。图文须对齐，留白用于分组，不掩盖欠缺设计。
