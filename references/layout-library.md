# 参考版式库

参考文件优先；以下适用于高校科研和技术汇报，按内容选结构，不强制每页相同密度。

以下为可编辑版960×540point候选规范；整页图片版正文优先执行image-titlebar-contract.md固定规范：边距32；标题x32/y18，30–34pt；横线y68；内容y78–466；页码右下。颜色取用户选定theme.json，白底、深中性色常规正文；不要默认深蓝/红或整页粗体。正文18–24pt，图内关键旁注通常14–16pt等效大小，实际投影可读优先。优先参考结构；过量内容先调整版式，不靠缩字塞入。

| ID | 内容 | 结构 |
|---|---|---|
| cover | 封面 | 主题主视觉＋标题/副标题/一次性身份信息，整体构图，不用突兀色块补救背景 |
| toc | 目录 | 真实章节递进路径、阶梯、模块或编号行，当前章节用选定主色 |
| demand | 需求 | 观点栏、图表/指标、场景图、结论 |
| problem | 问题 | 两行问题，每行2–3个图文模块，标签紧邻图片 |
| mechanism | 机理 | 大断面、准确编号引线、机制说明 |
| route | 路线 | 3–5模块、箭头、关系文字、整体目标 |
| comparison | 对比 | 同尺度两栏、准确几何/图表、差异结论 |
| metrics | 指标 | 分类矩阵或真实图表，区分阈值/实测 |
| cases | 案例 | 匹配场景、参数、效果证据；地图用可靠底图 |
| summary | 总结 | 分类标签、分行观点、红字关键词 |

标题横线、浅蓝观点栏、细边框、标签、底部结论栏用原生对象。图片承担解释任务；移除后信息完全不变时检查是否纯装饰。主体过小应裁切留白或补生成。图文须对齐，留白用于分组，不掩盖欠缺设计。

以上是布局候选而非逐页四件套。观点栏、结论栏和边框按内容需要选用，颜色使用主题浅色而非固定浅蓝。三页连续相同布局时评审适配性。研究机制图优先放大，政策页建立依据→要求→目标的关系；材料机理可加局部放大/标注，准确层位与文字用编号或引线匹配。

底部结论栏不是灰色注释区，禁止附加来源、待核、原稿页号和制作说明小字。图中必要旁注可与图片一体生成，不能强制拆分。封面和目录围绕主题独立构图，简约大气。

## 两条输出路径与预览机制（现行v2.6）

按[输出模式与预览](output-and-preview.md)执行：内容模式后独立选择可编辑/整页图片模式；默认前六页四风格缩略图替代三页样稿。展示四种标题栏并记录实际选择，选定后制作正式稿。整页图片模式不拆每个图标，不套用原生文字/图形编辑验收；逐字核验完整页面。正式PPTX默认系统桌面，用户指定路径优先。
