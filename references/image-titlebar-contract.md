# 整页图片版：标题栏物理规范（v2.6）

仅约束正式正文页，封面、目录、结束页独立设计。默认规范见 assets/image-titlebar-contract.json。用户已选T1—T4和主色后，将它复制到项目中，补充实际颜色、标题栏样式、字体与参考图路径；全稿只使用一个锁定版本。

## 固定几何与字号

基准画布1920×1080px，PPT物理画布960×540pt（33.8667×19.05cm）。坐标原点在左上，x向右、y向下；x/y为文字框左上角，不是字形外接框。

| 元素 | x/y（px） | 宽/高（px） | 字号 |
| --- | --- | --- | --- |
| 一级标题 | 96 / 48 | 1728 / 68 | 54px，粗体、左对齐 |
| 二级标题 | 96 / 132 | 1728 / 48 | 36px，常规、左对齐 |
| T3竖标记 | 56 / 48 | 8 / 64 | 固定形状 |
| 正文起点 | y≥216 | 按内容设计 | 独立正文层级 |

默认字体Microsoft YaHei；主题颜色锁定，T2主标题白字。T1横线、T2通栏和T4浅色区在首次正文标准页中确定坐标后登记，全稿固定，不能因正文变化挪动。T3采用上述竖标记，不随机改成徽章。

换算：pt=x_px×画布宽pt/画布宽px，cm=pt×2.54/72；字号采用相同比例。基准54px=27pt，36px=18pt。其他分辨率等比例缩放；不能把像素字号直接当成PowerPoint点数。画布物理尺寸改变时重新记录换算。固定字号是生成目标，无法从栅格图的字形高度反推精确字体字号。

## 生成与核验

1. 风格选定后，先从已锁定文案制作首张正式正文标准页。查看其标题位置、字形视觉大小、基线、行距、标记及正文边界；通过后保存同一标题栏参考图与规范。标准页属于正式制作阶段，不是风格选择前的逐页样稿。
2. 每张正式正文页的ImageGen请求同时提供完整数值规范、同一标题栏参考图及本页文案。明确标题栏几何优先于局部美化；只允许正文区变化。需要引用本地参考图时先查看，再用工具支持的参考图片参数传入，不能只在提示词中写文件名。
3. 长标题不得自动缩小、换位置或随机换行。先缩短章节标题，将具体内容写入二级标题且保留原意；确需双行须预先确认并另定统一规范。相近内容沿用同章标题。
4. 正式页完成后执行scripts/export_header_comparison.py，输出同尺度标题栏裁切对比图，查看全部正文页并记录titlebar_review（页号、通过/需改、实际偏差与复核结果）。这是辅助视觉检查，脚本不识别字体、不自动判定字号或坐标合格。
5. 核验左起点、顶部位置、视觉字号、文字基线、T3标记及正文边界。任何明显跳动都退回ImageGen修正或重绘，修复后重新核验。不要只记录“提示词一致”就通过。若反复修正仍达不到目标，报告具体偏差，不宣称精确一致；切换输出模式须用户确认。
6. Office仍只放一张整页图片，不叠加原生标题或遮挡补丁。标题栏参考组件可重复，场景配图不得跨页复用。缩略图不得作为标题栏验收依据。

命令（使用已有Python与Pillow；不自动安装）：

```powershell
python scripts/export_header_comparison.py --contract 项目/titlebar-contract.json --images 项目/正文01.png 项目/正文02.png --output 项目/header-comparison.png
```

state.json登记titlebar_contract_path、titlebar_reference_path、titlebar_comparison_path和titlebar_review；内容完整性仍单独逐页核验。
