# 分阶段工作流

## 项目目录

每次制作使用新的项目目录：`input/` 原材料、`planning/` 页面计划、`style-previews/` 风格稿、`assets/` 登记素材、`previews/` 正式导出图、`output/` PPTX、`state.json` 进度。不得把用户材料写入 Skill 发布仓库。

## 内容与参考样式

逐页提取标题、核心观点、正文、证据、来源、备注。读取参考 PPT 的内容和页面渲染，提取字体、颜色、标题位置、图片风格和留白；模板中的图片、校徽、母版图形不会自动获得素材使用授权。严格模式使用空白幻灯片重建，不直接继承模板母版。

依据内容量匹配布局：观点与证据并置、图像主导、比较、时间序列等，不为了整齐强行堆卡片。每页核心观点与视觉表达要对应。封面、目录和结束页同样明确目的；不能无证据塞入统计图。

## 四种风格

四套使用相同内容顺序、16:9（用户未指定时）和 2×3 缩略布局。至少一套紧贴参考文件，其余通过配色、图像语言、排版或视觉密度形成区别。制作大量素材之前确认重要缺项。生成耗时期间说明进度，不凭空给费用和时间保证。

ImageGen 提示词结构：任务类型、页面或素材用途、选定设计规范、主体及关系、比例、留白、背景/透明需求、文字约束、禁止多余元素。素材提示词优先不包含正文、标题及页码，避免与原生文字重复。

默认四种风格均用本机 PowerPoint 组装，预览保持素材受控。只有用户明确允许自由探索时，ImageGen 才可以对提供素材进行视觉组合，且仅用于设计方向；不能通过提示词把概率生成描述成确定性拼接。

## 正式制作

选择与继续均获授权后锁定设计规范，逐页计划中记录素材 ID 和位置。同类素材使用共同提示词与参考图，避免风格漂移。生成图像逐项检查后登记，再调用脚本。先导出前六页正式样稿（全稿少于六页则全部），显示用户实际可见的图片，确认后继续。

全稿组装后核对目录与章节、观点与证据、标题页码、裁切、中文字体、数据图形。确认效果图仅指最后交付文件的导出图。修改 PPT 后旧预览作废，必须更新。

## 权限

用户提供材料并请求制作即授权本次制作所需本地文件写入；不含不相关文件修改、安装依赖、外部素材搜索或发布。公开仓库仅包含 Skill 和无隐私示例。登录、付费、发布遵守当前会话授权与工具限制。
